# Idea artifact contract

For a new incubator idea, maintain these files as needed:

```text
incubator/ideas/IDEA-####/
├── idea.yaml
├── brief.md
├── problem.md
├── evidence.md
├── alternatives.md
├── market.md
├── competitors.md
└── evaluation.md
```

At intake, only `idea.yaml` and `brief.md` are mandatory. Create later artifacts when the corresponding workflow actually produces useful content.

## brief.md minimum

- Original idea
- Why it came up
- Intended user hypothesis
- Problem hypothesis
- Solution hypothesis
- Known constraints
- Assumptions
- Open questions

Never turn assumptions into facts merely to fill sections.
