# Evidence ladder

Use this as a qualitative evidence hierarchy, not a universal scoring formula.

Stronger evidence often includes:

1. Direct observation of repeated behavior or workflow.
2. Multiple independent user reports tied to actual recent behavior.
3. Behavioral data, transactions, support logs, or usage data.
4. Credible external research directly relevant to the target/context.
5. Search/community signals that indicate repeated demand.
6. Expert opinion.
7. Agent inference or persona speculation.

Always record recency, relevance, independence, and potential bias. Lower-level evidence can be useful for exploration but should not be presented as validation.
