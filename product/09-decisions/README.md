# Product OS Decision Records

Decision records in this directory are the authoritative product-level decisions referenced by `.product/state.yaml`.

`DEC-0001` and `DEC-0002` were reconstructed during v1.0.0 baseline normalization from explicit human approvals that occurred before the Decision Council implementation existed. No historical Council workspace is fabricated for those records.

`DEC-0003` records the explicit human instruction to normalize and submit the corrected v1.0.0 ZIP. It is a direct human-gated release decision, not a retrospective claim that an earlier Council existed.
