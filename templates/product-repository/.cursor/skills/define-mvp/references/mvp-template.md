# MVP scope template

```markdown
# MVP Scope

## Hypothesis being tested

## Riskiest assumption

## Target user / scenario

## Learning objective

## IN — required for the test

## OUT — explicitly excluded

## LATER — plausible future work, not MVP

## Critical user journey

## Minimum data / instrumentation

## Success / failure signals

## Decision after experiment
What evidence would support CONTINUE, PIVOT, or KILL consideration?

## Technical constraints
Only constraints required by the experiment/product.

## Risks
```

If the scope cannot fit on a concise list, challenge whether the MVP is actually minimal.
