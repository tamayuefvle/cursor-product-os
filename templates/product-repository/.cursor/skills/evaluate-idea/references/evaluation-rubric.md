# Evaluation rubric

Use the following dimensions as structured judgment, not a mechanical weighted score:

- **Problem strength** — evidence that a real, repeated, meaningful problem exists.
- **Evidence quality** — directness, independence, recency, relevance.
- **Alternative pressure** — how good current solutions/workarounds already are.
- **Differentiation potential** — meaningful reason to switch/adopt.
- **Business plausibility** — value capture and sustainable cost assumptions.
- **Feasibility** — MVP can test the riskiest assumption without disproportionate complexity.
- **Timing** — external conditions help or hurt now.
- **Founder/operator fit** — only when explicitly relevant; do not invent personal constraints.

For each dimension record:

- evidence;
- counter-evidence;
- confidence 0–100;
- what would change the judgment.

A high average does not override a fatal single risk.
